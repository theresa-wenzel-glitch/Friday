Einstellungen

Mit einem Anthropic-API-Key plant Claude für beliebige Ziele Ziele auf deine Lage zugeschnitten. Ohne Schlüssel plant Atlas ebenfalls jedes Ziel, aber nach allgemeinen Regeln.

So kommst du an einen Schlüssel
  1. console.anthropic.com öffnen und ein Konto anlegen.
  2. Unter Billing Guthaben aufladen — 5 € reichen für etwa 25 Pläne.
  3. Unter API Keys auf Create Key. Der Schlüssel wird nur einmal angezeigt.
  4. Hier einfügen und speichern.
Der Schlüssel bleibt in diesem Browser und wird nur an api.anthropic.com gesendet. Jeder Plan kostet etwa 0,15–0,20 € über deinen Anthropic-Account.
● Ein API-Key im Browser ist für den Eigengebrauch in Ordnung, für ein öffentliches Produkt nicht — dort gehört der Schlüssel auf den Server. Genau so macht es engine/.
● Diese Seite läuft über eine Internetadresse Der Aufruf an api.anthropic.com kann hier von der Sicherheitsrichtlinie der Seite blockiert werden. Wenn er fehlschlägt: die HTML-Datei herunterladen und lokal im Browser öffnen — dort geht es.
