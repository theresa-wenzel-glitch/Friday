# apps/web — noch nicht gebaut

Hier entsteht das Web-Dashboard fuer Unternehmen (Next.js + TypeScript).

**Warum noch nicht:** Ein Betrieb verwaltet seine Auftraege lieber am Computer
als am Telefon — das Web-Dashboard ist also wichtig. Es ist aber erst dann
sinnvoll, wenn feststeht, welche Ansichten ein Betrieb im Alltag wirklich
braucht. Das zeigt sich an der Nutzung der Mobile-App, nicht am Reissbrett.

**Was schon steht:** Die Bausteine, die die Web-App verwenden wird, sind
fertig — `@jobflow/types`, `@jobflow/validation` und `@jobflow/config` sind
bewusst frei von React-Native-Abhaengigkeiten und laufen unveraendert in
Next.js. Die API ist dieselbe.

Geplant fuer Phase 5 (siehe `docs/product/entwicklungsplan.md`).
